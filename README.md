#  Food Delivery System (DSA Mini Project)

A simple console-based Food Delivery System developed in C++ using various Data Structures and Algorithms (DSA).

This project demonstrates the practical implementation of Arrays, Linked Lists, Stack, Queue, Binary Search Tree (BST), Searching, and Sorting algorithms in a real-world food delivery scenario.

---

## 📌 Features

- Add Food Items
- Display Food Menu
- Search Food using Linear Search
- Search Food using Binary Search
- Sort Food Items by Price using Insertion Sort
- Add Customer Orders
- Display Orders
- Undo Last Order using Stack
- Process Deliveries using Queue
- Add Restaurants using BST
- Display Restaurants in Sorted Order
- Assign Delivery Boy

---

## 🛠 Data Structures & Algorithms Used

### Arrays / Vector
Used for storing food items.

### Linked List
Used for storing customer orders.

### Stack
Used for Undo Last Order functionality.

### Queue
Used for Delivery Scheduling.

### Binary Search Tree (BST)
Used for Restaurant Management.

### Linear Search
Used for searching food items by name.

### Binary Search
Used for searching food items by ID.

### Insertion Sort
Used for sorting food items based on price.

## ⚡ Time Complexity Analysis

| Operation | Complexity |
|------------|------------|
| Add Food Item | O(1) |
| Display Food Menu | O(n) |
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Insertion Sort | O(n²) |
| Add Order | O(n) |
| Stack Push/Pop | O(1) |
| Queue Push/Pop | O(1) |
| BST Insert | O(log n) (Average) |
| BST Traversal | O(n) |
